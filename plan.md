# Furry Friends Co. — Google Sites Build Guide (v2)

A complete, Google Sites–only blueprint for Diya & Pari's pet care business in Katy, TX 77494. No code, no custom CSS, no embeds beyond the Google Form. Built mobile-first to feel warm, cute, modern, local, and trustworthy.

---

## 0. Brand Quick Reference

**Colors**
| Role | Hex |
|---|---|
| Deep green (headings, footer, alt buttons) | `#1F4D34` |
| Sage green (secondary accents) | `#A8C0A0` |
| Light sage (alt section background) | `#E8EFE3` |
| Cream (main background) | `#FAF5EE` |
| Warm coral (primary CTA buttons) | `#E8956B` |
| Warm charcoal (body text) | `#3A3530` |

**Fonts (max 2)**
- Headings: **Playfair Display**
- Body + buttons: **Nunito**

**Primary button (everywhere):** `Request a Pet Visit` → Google Form (link TBD)
**Secondary buttons:** `View Services`, `Meet Diya & Pari`, `Read Reviews`, `Open the Request Form`

**Setup once in Google Sites:**
1. New Site → Theme: **Impression** → Customize → set accent to `#E8956B`, font style → headings Playfair Display, body Nunito.
2. Settings → Navigation → **Top**, Mode: **Modern**.
3. Settings → Brand images → upload paw + "FF" logo and a square favicon.
4. Settings → Custom domains → set later if you get one.

## 3. Image Sourcing Guide

Use real photos wherever possible. Get owner permission before posting any pet's photo.

**Free stock fallback:** Unsplash, Pexels, Pixabay. Search terms: "dog walk suburb", "cat being petted", "golden retriever neighborhood", "puppy cozy", "cat by window", "leash hook home", "pet sitter".

**Image specs:**
- Upload at **1600 px wide** max (smaller files = faster mobile).
- Hero: landscape (16:9 or 3:2).
- Cards: square (1:1).
- Mini About / story sections: 4:3 or 3:2.
- Avoid heavy text-on-image — let Sites overlay the text.
- Keep palette consistent — warm light, green/cream tones. Skip blue-tinted or harsh corporate photos.

**Per-page image checklist:**
- Home: 1 hero + 4 service thumbnails + 1 sisters photo + 3 "update" photos + 1 CTA banner = ~10 images
- Services: 5 service images + 1 CTA backdrop
- Meet: 1 hero of sisters + 1 candid with pet
- Reviews: up to 3 round pet photos (optional)
- Safety: 1 hero, 1 meet-and-greet photo
- Request: optional 1 soft hero, no other images needed

## 5. Mobile-Friendly Notes

- Design for the **~390 px width** phone first.
- Use **Layout blocks only** — never manually positioned text boxes (they overlap on phones).
- One idea per section. Long sections = endless scrolling on mobile.
- Headlines ≤ 8 words. Subheads ≤ 20 words.
- Buttons: keep label short. "Request a Pet Visit" is the longest acceptable.
- 3- and 4-column layouts stack automatically on mobile — design cards so they read well stacked.
- Images: square cards work best when stacked.
- Embedded Google Form: height ≥ 900 px.
- Avoid carousels for important info.
- Footer: 3 short lines max.
- Always Preview → phone icon (bottom right) → scroll every page top to bottom before publishing.

## 7. Polish Tips (no code needed)

- **Section rhythm:** alternate backgrounds white → cream → light sage → white. Never stack two same-color sections in a row.
- **Rounded everything:** use Sites' circular image crops for pet photos and sister portraits. Feels softer and more modern.
- **Dividers:** use thin sage-green divider lines (Insert → Divider, then color) to separate dense sections.
- **Generous padding:** set hero and CTA sections to **Large** padding, content sections to **Medium**. Cramped = cheap.
- **Consistent card heights:** when filling cards, keep descriptions to a similar length (1 short sentence). Uneven cards look broken on mobile.
- **One emoji rule:** use a single 🐾 in the footer or sisters' intro for warmth. Don't sprinkle emojis everywhere.
- **Image overlays:** when text sits over a photo, use a sage/cream color overlay at 40–60% opacity (Sites' built-in overlay slider) so text stays readable.
- **Repeat the CTA:** every page ends with a coral CTA banner. Always.
- **Trust signals:** keep the small "Serving Katy 77494 · 24-hour response" line near every primary CTA.
- **Short video clip (optional):** a 10–20s clip of a happy dog greeting on a walk, uploaded as Unlisted YouTube, embedded once on Home below "Photo Updates" section. Don't autoplay with sound.
- **Avoid:** clipart pets, neon colors, drop shadows, all-caps headings, three+ fonts, full-page text walls.
